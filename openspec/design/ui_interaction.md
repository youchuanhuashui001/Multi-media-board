# UI 交互设计与分析

## 1. 当前架构概览

系统遵循由 `view_manager` 管理的 **中心辐射 (Hub and Spoke)** 导航模型。

*   **中心 (Hub/Home)**: `main_view` - 中央启动器。
*   **辐射 (Spokes/Apps)**: `audio_view`, `book_view`, `video_view`, `photo_view`, `setup_view`。
*   **导航管理器**: `view_manager` 处理视图切换、生命周期 (`init`, `show`, `hide`, `destroy`) 和全局手势。

## 2. 导航流程

### 2.1 出站 (主页 -> 应用)
*   **触发**: 点击 `main_view` 上的图标。
*   **机制**: `view_manager_switch_to("app_name")`。
*   **行为**:
    *   隐藏当前视图 (`hide()` 回调)。
    *   初始化新视图（如果是首次 `init()`）或显示 (`show()`)。

### 2.2 入站 (应用 -> 主页)
*   **触发**: **全局上滑手势** (从屏幕底部)。
*   **机制**: `view_manager.c` 中的 `view_gesture_event_cb`。
*   **视觉提示**: 屏幕底部的半透明白色条 (`indicator_bar`)。
*   **行为**: 切换回 `main_view`。

### 2.3 内部导航
*   **电子书视图**:
    *   **书架 -> 阅读器**: 点击书籍封面。
    *   **阅读器 -> 书架**: 点击屏幕中心显示“返回”按钮，然后点击“返回”。
    *   **翻页**: 点击屏幕左/右侧。

## 3. 功能设计建议

### 3.1 状态持久化 (电子书视图)
**当前问题**:
*   从 *阅读器* 界面上滑返回主页时，隐藏视图但未显式保存阅读进度。
*   目前仅在点击内部“返回”按钮时保存进度。

**建议**:
*   在 `book_view_hide()` 中实现状态保存。
*   这确保无论用户如何离开电子书（返回按钮或上滑），进度都会被保存。

### 3.2 后台音频播放
**当前行为**:
*   `audio_view` 隐藏 UI 但 `audio_manager` 继续播放。这对于后台播放是正确的。

**建议**:
*   **迷你播放器 / 状态**: 当在 `main_view` 或 `book_view` 时，如果音乐正在播放，提供视觉指示（例如状态栏中的小图标或悬浮按钮）。
*   **音频焦点**:
    *   进入 `video_view` 必须暂停音乐播放。
    *   进入 `book_view` 应 *继续* 音乐播放（边读边听）。

### 3.3 交互一致性
*   **手势**: “上滑”手势非常好。确保它在所有新视图 (`video`, `photo`) 中都启用。
*   **视觉反馈**: 确保 `indicator_bar` 在所有应用背景之上可见（已由 `lv_layer_top()` 处理）。

## 4. 实施路线图

1.  **重构电子书视图**: 将保存逻辑移动到辅助函数；从 `hide()` 和 `back_btn` 调用它。
2.  **音频焦点**: 初始化 `video_view` 时添加 `audio_manager_pause()` 调用。
3.  **视觉打磨**: 验证 `indicator_bar` 在所有主题/背景下的可见性。
