# Part 3: 代码实现 (v2.0)

## 3.1 关键逻辑流程

### 3.1.1 歌词滚动与高亮

**目标**: 显示约 7 行，当前行居中并高亮，支持切歌重置和进度回退。

**实现 (`update_lyrics`)**:
1.  **状态管理**:
    *   **切歌检测**: 使用 `static music_info_t *last_music_ptr`。如果 `info != last_music_ptr`，重置 `last_index = 0`。
    *   **回退检测**: 获取当前播放时间 `pos`。如果 `pos < last_pos` (说明发生了单曲循环重播或向后拖动)，重置 `last_index = 0`。
    *   更新 `last_music_ptr = info` 和 `last_pos = pos`。

2.  **构建文本缓冲区**:
    *   范围：`[current_index - 3, current_index + 3]` (共 7 行)。
    *   循环 `i` 从 `start` 到 `end`:
        *   **越界处理**: 如果 `i` 超出范围，添加空行 `\n` 以保持布局稳定。
        *   **高亮格式**:
            *   当前行: `#0000ff line_text\n#` (蓝色高亮)
            *   其他行: `#000000 line_text\n#` (黑色)
            *   **注意**: 换行符 `\n` 必须包含在颜色块内部，否则 LVGL 解析可能会出错导致换行异常。

3.  **UI 设置**:
    *   容器位置: `(450, 0)`，尺寸 `500x450`。
    *   隐藏滚动条: `lv_obj_set_scrollbar_mode(..., LV_SCROLLBAR_MODE_OFF)`。
    *   增加行间距: `lv_obj_set_style_text_line_space(..., 10, 0)`。

### 3.1.2 统一更新逻辑 (Unified Update)

为了解决初始化与运行时更新的逻辑复用问题，采用了 **自动检测更新** 模式。

**函数**: `update_mete_data()`
*   **职责**: 更新静态信息（封面、歌名、歌手）。
*   **逻辑**: 内部维护 `static last_info`。每次调用时对比当前歌曲 `info`。如果发生变化（切歌或初始化），则加载新的封面和文本。

**函数**: `update_timer_cb()`
*   **职责**: 定时器回调（100ms）。
*   **逻辑**:
    1.  调用 `update_mete_data()`: 自动检测并更新静态信息。
    2.  调用 `update_progress()`: 更新进度条和时间。
    3.  调用 `update_lyrics()`: 更新歌词滚动。

这种设计使得 `audio_view_init` 只需创建 UI 骨架，而数据填充完全由定时器逻辑驱动（或在初始化时显式调用一次 `init_song_info` 复用逻辑），避免了代码重复。

### 3.1.3 播放列表弹窗

**实现**:
*   **容器**: 全屏半透明黑色背景，默认隐藏 (`LV_OBJ_FLAG_HIDDEN`)。
*   **内容**: 居中面板 + `lv_table`。
*   **交互**:
    *   点击 "播放列表" 按钮: 移除 HIDDEN 标志。
    *   点击列表项 (`LV_EVENT_VALUE_CHANGED`): 获取选中行 -> 转换为歌曲索引 -> 播放 -> 隐藏弹窗。

# Part 4: 后续开发步骤详解

## 4.1 Step 4: 播放列表弹窗 (Playlist Popup)

### 4.1.1 目标
实现一个半屏的模态弹窗，显示当前播放列表，允许用户点击切歌。

### 4.1.2 UI 结构
*   **遮罩层 (`playlist_popup`)**:
    *   尺寸: 全屏 (1024x600)
    *   样式: 黑色背景，透明度 60% (`LV_OPA_60`)
    *   状态: 默认隐藏 (`LV_OBJ_FLAG_HIDDEN`)
*   **列表容器**:
    *   尺寸: 800x500
    *   位置: 居中
    *   样式: 深灰色背景 (`#1e1e1e`)，圆角 (10px)
*   **歌曲列表 (`playlist_table`)**:
    *   列 1: 序号 (宽 80)
    *   列 2: 歌曲名 (宽 350)
    *   列 3: 歌手 (宽 200)
    *   列 4: 时长 (宽 100)
    *   字体: 20号字体
*   **关闭交互**: 点击遮罩层空白处关闭（可选），或添加专用关闭按钮。

### 4.1.3 交互逻辑
1.  **打开**:
    *   触发: 点击主界面 "播放列表" 按钮。
    *   动作: `lv_obj_remove_flag(g_audio_view.playlist_popup, LV_OBJ_FLAG_HIDDEN)`。
2.  **播放**:
    *   触发: 点击表格行 (`LV_EVENT_VALUE_CHANGED`)。
    *   动作:
        *   获取选中行号 `row`。
        *   计算歌曲索引 `index = row - 1` (第0行是表头)。
        *   调用 `audio_manager_play_at_index(index)`。
        *   隐藏弹窗。
